# Web Portfolio

웹 퍼블리셔 · UI/UX 디자이너 포트폴리오 사이트입니다.

실무에서 직접 참여한 프로젝트를 중심으로 주요 작업 내용과 기여도를 정리했습니다.  
사이트의 기획, 디자인, 퍼블리싱을 직접 진행했으며 반응형 웹과 웹 접근성을 고려하여 제작했습니다.

## Live

포트폴리오 바로가기 (https://seongmi-hong.github.io/seongmis-portfolio/)

## Tech Stack

- HTML5
- SCSS
- JavaScript
- jQuery
- Figma

## Features

- PC / Tablet / Mobile 반응형 웹 구현
- Light / Dark Theme 지원
- Intersection Observer 기반 스크롤 인터랙션
- 시맨틱 마크업 및 웹 접근성을 고려한 구조 설계
- Open Graph 및 기본 SEO 설정
- 이미지 WebP 변환 및 최적화
- 로컬 웹폰트 적용 및 로딩 최적화

## Directory Structure

```text
portfolio/
├─ css/          # 컴파일된 CSS
├─ fonts/        # 로컬 웹폰트
├─ images/       # 이미지 리소스
├─ js/           # JavaScript
├─ projects/     # 프로젝트 상세 페이지
│  ├─ 3dmat/
│  ├─ dam/
│  ├─ industrial/
│  └─ seongsu/
├─ scss/         # SCSS 소스
├─ favicon_512.png
└─ index.html
```

## Projects

포트폴리오에는 실무에서 참여한 프로젝트를 중심으로 작업 과정과 담당 업무를 정리했습니다.

- 대규모 산업 시설 통합 관리 솔루션 (https://seongmi-hong.github.io/seongmis-portfolio/projects/industrial/)
- 성수 POC 온라인 쇼룸 (https://seongmi-hong.github.io/seongmis-portfolio/projects/seongsu/)
- AWAS-3DMAT (https://seongmi-hong.github.io/seongmis-portfolio/projects/3dmat/)
- 드론 영상기반 댐시설물 지능형 진단체계 구축 (https://seongmi-hong.github.io/seongmis-portfolio/projects/dam/)

각 프로젝트의 상세 내용은 포트폴리오 사이트에서 확인할 수 있습니다.

## Publishing

- GitHub Pages를 통한 정적 웹사이트 배포
- SCSS 기반 스타일 관리
- BEM 방식의 클래스 네이밍
- 반응형 레이아웃 구현
- 키보드 접근성과 시맨틱 HTML을 고려한 마크업
- Lighthouse 및 W3C Validator를 활용한 최종 QA
